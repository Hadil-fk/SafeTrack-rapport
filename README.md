# SafeTrack Mobile

SafeTrack is a comprehensive security and tracking mobile application built with Flutter. It provides real-time location tracking, geofencing, SOS emergency calls, and local notifications to ensure safety for families and teams.

## Key Features

- **Real-time Tracking**: Monitor device locations in real-time with background service support.
- **Geofencing**: Create and manage safe zones with automated notifications for entry/exit events.
- **SOS Emergency Calls**: Quick-access SOS button to initiate calls to emergency contacts.
- **Biometric Login**: Secure and fast authentication using fingerprint or face recognition.
- **Notifications**: Local and push notification support for critical status updates.
- **Cross-Platform**: Optimized for Android, iOS, and Web.

## Getting Started

1.  **flutter pub get**: Install dependencies.
2.  **Firebase Setup**: Ensure `google-services.json` (Android) and `GoogleService-Info.plist` (iOS) are correctly placed.
3.  **Permissions**: Ensure background location and notification permissions are granted on the device.
